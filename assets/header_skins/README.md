# 头部皮肤素材 / Header skin assets

本目录存放「图片皮肤」用的 SVG 素材。

- **模板**:[`example_skin.svg`](example_skin.svg)
- **完整创作规范见项目根 [README.md「🎨 头部皮肤创作指引」](../../README.md#-头部皮肤创作指引)** —— SVG 要求 + 接入三步。

速记:全幅设计(`BoxFit.cover` 铺满)、只用内联 `fill`(**勿用 `<style>` CSS**,否则渲染成黑块)、勿放 `<text>` / 签名水印、第三方素材需 CC0 / MIT 并注明出处。
