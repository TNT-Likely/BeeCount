# Agent Instructions

## Localization

- For localization changes, do not proactively translate new or changed strings into Korean (`app_ko.arb`) or Traditional Chinese (`app_zh_TW.arb`). Update those locales only when the user explicitly asks.
- Leave existing Korean and Traditional Chinese translations unchanged unless the user asks to edit them.
- This preference applies to agent work; follow the project's localization generator and fallback behavior for untranslated entries.
