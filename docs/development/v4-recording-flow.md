# V4 核心记账流程

更新：2026-10-24。分支：`v4`。记账主页面仍处于完整验收中；附件预览子页面已完成。以 [页面完成标准](v4-page-completion.md) 判定交付，不以组件接入或入口打开计数。

## 当前入口

`TransactionEditorPage` 的新增、编辑、复制和转账入口默认使用新版。临时 `useV4` 对比开关与活动源码中的旧录入 UI 分支已移除；旧源码保存在 `.docs/v4-ui-migration/backup`，准备上线前保留。

`BEECOUNT_V4_RECORDING=true` 用于调试验收入口：首页右上更多 → V4 组件验收/深浅色切换。它不再决定记账页的新旧布局。验收页是原 App 中的普通 Flutter 路由。

真机继续使用同一个独立 QA 包。每次更新前核验 APK 实际包名、Provider、签名，私密备份现有 QA 数据，确认更新前后数据库一致；用户原安装包不被替换或清空。

## 录入布局和能力

- 普通卡片为默认外观，沿用当前主题色与深浅色。顶部收支/转账切换使用 `RecordingHeader` 和基础包紧凑 `BeeSegmented`。
- 金额、两行信息、键盘与保存区固定；分类占用剩余高度并独立滚动。表单到键盘保留 8 logical px。
- 第一行直接编辑备注、访问历史备注，右上添加附件；第二行显示账户、日期、紧凑标签。顶部更多打开账单标记弹窗。
- 一级/二级分类带图标，自定义图片保留原色并提供失败回退。主编辑器二级区域最多两行（92 logical px），超出后内部滚动；更多分类弹层可搜索、完整展开并通过确认提交草稿。
- 加减乘除、独立等号、退格/长按清空、保存时结算继续使用原有 Decimal 和从左到右计算规则。
- 币种、真实账户、横排多选标签、历史备注、附件来源和滚轮日期/时间均接入原数据与服务。外币保留折算预览、历史汇率快照、手动汇率及缺失汇率阻断。
- 新建时可切账本；有草稿先确认，取消保留草稿，确认后清空并改用新账本币种。编辑和复制保持原账本。保存前重新核对账本上下文及分类有效性。
- 未改动的空白收支切换使用各自默认账户；已有草稿及用户明确选择“不设置账户”时保留当前选择。
- 保存防重复；后续标签等步骤失败时保留已创建交易 ID，重试更新原身份。“再记一笔”完成后清空金额与分类，留在录入页。
- 转账使用账户对业务组件和原转账提交服务；历史外币快照保持。是否放开原账户币种范围、弹层是否重复放收支页签等产品问题见 [待确认事项](v4-migration-questions.md)。

## 数据与组件边界

| 位置 | 职责 |
| --- | --- |
| `packages/beecount_ui` | 主题、通用控件、紧凑分段、弹窗、来源弹层与反馈 |
| `packages/beecount_business_ui` | 录入头部、金额/折算、分类、两行表单、键盘和转账账户对；接收展示数据与回调 |
| `lib/presentation/v4/bindings/recording_category_section.dart` | 分类查询、共享账本过滤、图片适配、完整分类弹层、错误与重试 |
| `lib/presentation/v4/bindings/recording_save.dart` | 原 Repository 写入、共享资源引用、标签/附件、作者标记、同步与统计刷新 |
| `lib/widgets/biz/amount_editor_sheet.dart` | 沿用原计算、汇率、日期、备注、账户、标签与草稿状态，组合新的展示组件 |
| `lib/pages/transaction/transaction_editor_page.dart` | 参数、初始化、类型/分类选择、页面组合、保存/重试身份与导航；约 400 行 |

纯 UI 包不依赖主 App、Riverpod、Drift 或网络。没有新增第二套 Repository、数据库 schema 或同步协议。大型金额状态机仍在 App；不把它整块移动进业务 UI 包来声称完成组件化。

## 短屏与输入法

按完整安全视口高度分档（阈值 720 logical px），不因输入法打开而切换密度。

- 长屏由分类使用剩余空间；数字键盘和保存区贴底。
- 短屏金额/币种/账本横排，外币保留一行折算；备注默认折叠，点图标原位展开编辑。
- 窄屏二级分类改为两列，图标、可读文字和 44 logical px 触控高度保留。
- 系统键盘覆盖底部时收起数字键盘，保存区位于输入法上方；浮动/收起输入法的一像素占位不触发收起。
