# v4 核心记账流程首版

日期：2026-10-24。分支：`v4`。状态：收支录入与 Widget 回归已落地，持续人工验收，尚未发布。

## 试用入口

开发构建增加 `--dart-define=BEECOUNT_V4_RECORDING=true`。首页记账、快捷记账及已有编辑/复制入口中，`TransactionEditorPage(quickAdd: true)` 会使用新录入界面。未启用时继续使用原来的分类页和金额弹窗。

Widget 测试也可以显式传 `useV4: true/false`，同时验证新旧入口。此开关只选择 UI，不新建数据库或同步引擎。

安卓真机试用使用独立应用 ID 和“蜜蜂记账 4.0 验收”名称，安装前核验 APK 包名、FileProvider 与签名；不会替换设备上原有的测试版或读取其数据。环境与证据保存在私有 QA run，独立报告另行导出。

## 本轮已实现

- 默认普通卡片布局，继承当前主题色，支持深浅色；金额卡、分类卡与备注信息卡分区。
- 支出/收入切换，金额、备注、账户与标签草稿保留；切换后重新选择对应类型分类。
- 加减乘除均直接可点，等号单独计算，保存也可以直接结算当前表达式；沿用原有 Decimal、从左到右计算及两位小数规则。
- 一级分类与二级分类原地展开，二级分类带图标；自定义图片继续走原有解析器，图片缺失回退图标。
- 更多分类底部弹窗、完整分类列表、一级/二级选择及现有分类管理入口；返回后保留录入草稿。
- 备注在第一行直接编辑，附件移到右上角；账户、日期、紧凑标签在第二行。账户弹层、标签横排多选、附件复用现有能力，历史备注入口仍需随关联弹窗迁移核对；顶部更多打开账单标记弹窗。
- 币种搜索弹窗、切换币种后重置账户并按币种筛选、折算预览、编辑历史汇率快照、手动汇率弹窗和缺失汇率阻断。
- 滚轮日期选择；开启交易时间时继续使用现有日期/时间两步选择。
- 底部按定稿保留“再记一笔／等号／保存”三段操作；连续记账完成后清空新草稿并留在录入页。
- 保存中防连点与返回保护；离开未保存草稿需确认，取消确认可以继续编辑。
- 保存失败保留草稿并允许重试；后续标签等步骤失败后重试复用已创建的交易 ID，避免重复创建账单。
- 共享账本分类通过既有 Owner 镜像与 synthetic ID 规则接入，写入继续使用原有 override 字段。

新建记账时可从金额卡片切换账本；有草稿先确认放弃，取消保留原草稿。编辑与复制沿用原账本。外部切换账本时阻止不匹配上下文的保存。金额显示货币符号与两位小数；预设分类使用与定稿同源的 Lucide 线性图标，自定义图片保留原图。

## 数据与包边界

| 位置 | 本轮职责 |
| --- | --- |
| `packages/beecount_ui` | 主题令牌、卡片、线性图标及通用基础组件，详见组件覆盖文档 |
| `packages/beecount_business_ui` | 记账组件及其他业务展示组件；接收数据、插槽和回调 |
| `lib/presentation/v4/bindings/recording_category_section.dart` | 按 ledgerId/kind 查询分类，监听同步刷新，处理共享账本过滤与图片适配；加载/失败/重试与更多分类弹窗 |
| `lib/widgets/biz/amount_editor_sheet.dart` | 复用原有金额、汇率、备注、账户、日期、标签、附件与草稿状态；增加 v4 布局分支 |
| `lib/pages/transaction/transaction_editor_page.dart` | UI 开关、类型/分类组合、真实保存与现有后处理；新旧界面共用同一保存方法 |

此阶段没有把大型金额编辑器整块搬进业务组件包。它对 App Provider、附件服务等的依赖先保留，再按实际复用需求提取状态与命令。不存在独立数据请求包、第二套 Repository、数据库 schema 或同步协议迁移。

## 保留与后续

转账继续使用现有 `TransferForm` 与金额弹窗；切换至转账前先确认放弃当前草稿。转账卡片布局、动态皮肤、完整 v4 首页/底栏和所有关联管理页尚未在本轮迁移。

附件入口复用原有相册、相机及预览功能，本轮没有在设备上验收平台相册/相机、权限或 Cloud 双向同步；不能以 Widget 测试代替这些发布前验收。

两个包已补充当前设计规范的 45 组组件映射，并提供两张 App 内 Flutter 验收页；详见 [组件包覆盖与验收](v4-component-packages.md)。界面组件覆盖不代表其他业务页面已接入。数据包和工具链升级仍在 4.0 交付关键路径之外。

## 验证与截图

新增流程测试：`test/widgets/v4_recording_flow_test.dart`。使用 `NativeDatabase.memory()`，覆盖真实保存/连续记账、四则运算、小数、更多分类、草稿取消、外币编辑、币种/账户/标签、保存失败/防重、共享分类、自定义图片/回退、缺失汇率和旧入口。

```sh
flutter test --no-pub test/widgets/v4_recording_flow_test.dart
```

当前记账流程包含 25 项测试；连同组件目录、真实绑定、币种、共享过滤和原账单行时间对照共 73 项。以本次执行结果为准，不用历史截图替代当前构建。

金额和元信息固定，只有分类占剩余空间滚动；表单与键盘保留 8 logical px。系统键盘出现时收起计算器，保存按钮留在输入法上方。V4 确认和汇率编辑使用 BeeDialog。`RecordingConversionSummary` 使用双列紧布局，说明在左，金额/箭头在右；短金额、长金额、320 宽与 1.4 倍字体均验证右边界，防止 Flexible 留白使金额停在中间。

二级分类在主编辑器中最多占两行（92 logical px），超出后在分类内滚动；更多分类弹层保留完整展开。

## 短屏适配

按完整安全视口高度分档（当前阈值 720 logical px），不因 IME 打开导致密度切换。

- 长屏：金额、两行元信息、数字键盘和保存固定；分类使用剩余高度展示更多选项，超出时滚动。
- 短屏：金额/币种/账本横排，外币保留一行折算。备注默认折叠，点图标原位展开输入；账户、日期、标签、附件仍可达。辅助行已移除。
- 窄屏：二级分类由四列改为两列，保留图标与可读文字、两行高度及内部滚动。
- 系统键盘覆盖底部时收起数字键盘；浮动/收起输入法的一像素占位不触发收起。数字键与保存不按屏幕高度压缩，保留 44 logical px。
- 375×667 和 320×568 均包含 20 顶部安全区、普通/1.4 倍字体，验证分类滚动后金额和快捷操作不移动，日期弹层可打开。仅为 Flutter 视口测试，不代表对应旧型号的 iOS 系统兼容和真机键盘已测试。
