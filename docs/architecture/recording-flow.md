# 记账流程契约

`TransactionEditorPage` 负责新增、编辑、复制和转账的页面入口；金额计算与保存状态留在 App，录入布局由业务 UI 包组合。既有页面备份与逐轮执行记录在本机忽略的 `.docs`。

- 顶部使用紧凑收支/转账 Tab。金额、两行元信息、数字键盘与保存区固定；分类独占剩余高度并滚动。元信息到键盘保留 8 logical px。
- 元信息第一行原位编辑备注，右上角附件；第二行账户、日期与紧凑标签。短屏可折叠备注，点按后原位展开。
- 二级分类默认每行四格；按实际文本测量，溢出者占两格，保持原顺序。仅分类区滚动，不能把账户和备注随分类卷走。自定义图片填满图标区并保留失败回退。
- 数字计算沿用原 Decimal 与从左到右四则规则；独立等号、退格、长按清空、保存时结算保持原语义。
- 币种、账户、历史备注、标签、附件与日期均接原服务。外币保留原币、折算预览、历史汇率快照、手动汇率与缺失汇率阻断。
- 新建可切账本：有草稿先确认，取消保留，确认后清空并使用新账本币种。编辑/复制保持原账本；保存前重核账本上下文与分类身份。
- 空白收支切换保留各自默认账户；已有草稿或明确“不设置账户”时保留选择。
- 同屏录入转账账户对和金额。新增只允许同币种账户，可在其他本位币账本选择同一外币账户对；历史跨币种编辑沿用快照，复制作为新增仍受同币种限制。
- 保存防重复。后续标签/附件失败保留已创建交易 ID，重试更新原身份；再记一笔完成后清空金额与分类。
- 视口密度按完整安全高度决定，打开输入法不切换密度。系统键盘覆盖时收起数字键盘，保存动作保持可达。

页面组合与应用适配按 `lib/pages/transaction/recording` 组织，基础控件在 UI 包，录入、金额折算、分类、表单与键盘在业务 UI 包。存储、共享身份、汇率和同步继续属于 App；不通过把整个状态机移动进业务包来完成组件化。

长期产品决定见 [V4 行为约定](../decisions/v4-product-behavior.md)。几何、真实内存库读写、失败重试、历史快照、取消与导航分别验收，原生截图不能代替数据字段核对。
