# UI 组件规范

本规范对应本轮卡片方案，与 [交互原型](../prototype/demo.html) 使用同一份产品样式和组件样例。可视化入口为 [ui-components.html](ui-components.html)，导出图在 `../boards/ui-components-{light,dark}.png`。

## 基础规则

| 项目 | 本轮提案 |
| --- | --- |
| 基准画布 | 398 × 844；适配窄屏，长页面保留完整导出 |
| 页面左右留白 | 17 |

## 分类图标与自定义图片

主分类图标置于约 34–39 的背景槽，图像本体约 24–25；二级图标通常 16，二级图片 20。列表、排行、分类详情和账单详情的预设分类图标统一使用中性底和中性色线条；分类选择器仍按选中/未选中区分。自定义图片保留原色，由容器、边框和勾选表达选中。

- 完整显示：适用于透明 PNG、边缘留白完整的图案，不拉伸宽高比。
- 方形裁切：适用于照片或方形图片，中心裁切预览，实际落地接原有裁切流程。
- 加载中：保持相同槽位，显示占位，不能让文字跳动。
- 失败：回退到通用分类图标，分类名称与点击行为保留。
- 名称相同不意味着图标相同；真实实现应使用分类实体的 `iconType`、`icon` 和 `customIconPath`。

透明图和方形图示例只用于展示适配场景。上传示例在 HTML 内存中预览，不执行真实图片同步。

## 多币种与账单入口

- 首页通过 `showBrand` 偏好保留“显示蜜蜂记账”和“无品牌”两种状态；预览与个性化设置可切换，AI、多币种和明细交互共用。
- 首页品牌沿用现有顶部区域，以蜜蜂标志、中文字标和次行账本呈现；不增加独立大标题区。
- 账单行图标点击进入实体分类详情，包括当前二级分类；文字和金额进入账单详情。两个按钮为同级节点，最小图标点击区域 49 × 53，避免嵌套按钮和长按后误跳转。
- 原币金额为主要层级，例如 `−US$12.00`；次行显示 `≈ ¥85.20`，标签仍使用原有语义色。相同币种不显示重复折算。预设分类图标保持中性色，选中态再使用主题色；自定义分类图片不染色。
- 币种选择位于金额卡片，使用可搜索底部弹层，展示代码、名称、符号、示例汇率和选中勾选。关闭保留原草稿；选择其他币种后清空账户，同币种账户选择保持不变。
- 账户弹层只显示所选币种的账户，并允许暂不设置。记录页直接展示折算值；汇率获取中有状态，获取失败后可打开补充汇率弹窗，确认有效正数后恢复预览，取消不写入。
- 保存原币、原始金额、汇率与账本币金额快照。编辑或复制旧账单沿用当时汇率；编辑仅更新原账单，不新增重复项。
- 首页日/月合计、搜索、分类/标签汇总和批量合计均使用账本币快照；隐藏金额同时隐藏原币与折算金额。小票、详情保留原币信息。
- 原型汇率为固定示例；真实实现继续复用现有币种选择、汇率服务和金额编辑组件。

## 我的资料与当前账本

昵称与固定宣传语分层，点按昵称直接打开原有风格的编辑弹窗，头像与顶部设置仍可进入资料菜单。昵称最多 20 字，空白不能保存，取消保留原值；未设置时展示“设置昵称”入口。

当前账本卡片约 90 高：一行账本/余额标题，一行金额与“天 / 笔”统计，合并重复标题和分隔留白。承接原有累计余额、记账天数和账单笔数，移除占据首页级位置的账本数量。切换账本后金额和统计同时切换；单账本仍直接展示同一张卡片。当前余额继承现有 `currentBalanceProvider` / `getLedgerStats` 语义，不用本月结余或全部账户净资产替代。演示数据独立于月份筛选，原币新增记录使用账本币快照影响余额。

隐藏金额与首页使用相同全局状态；昵称和隐私属于全局偏好，页面返回不会恢复旧值。

## 账单附件

附件直接平铺图片：单张使用较大横向预览，两张并排，更多图片用三列网格。缩略图保留原图颜色并显示放大标志；点按打开完整图片，并提供张数、文件信息和选中缩略图切换。关闭或 Escape 返回原账单与原位置；无附件不展示空卡片。

`prototype/assets/attachment-*.png` 为合成支付凭证、小票和订单图；可运行 `scripts/build-attachment-assets.cjs` 重建，不读取真实账单或设备数据。

## 标签多选

标签横向排列并换行，保留既有语义色；勾选和边框同时表达选择，避免只靠颜色。顶部搜索在大量标签时缩小范围，已选数量固定可见，底部确认和清空不随标签列表滚走。大量场景只让标签区滚动。

## 账本操作

本地创建者可编辑、查看预算、清空、仅删除本地或删除账本；共享账本增加成员与成员统计。可编辑成员隐藏创建者操作。仅删除本地与删除云端数据必须区分，破坏性操作另有确认。

右下角 `⋯` 和卡片长按进入同一个菜单，不能维护两套不同的操作。进入某账本预算或成员页时，页面上下文应与目标账本一致。

## 同步状态

保留现有 `SyncDiff` 对应文案：未登录、未配置云端、云端暂无数据、已同步、本地有更新、云端有更新、本地与云端有差异、状态获取失败。

首次加载和刷新用检查中状态；同步过程显示进度；离线属于错误的具体原因。成功有勾选；差异和错误有可识别图标；失败详情展示原因、保留本地数据的状态以及重试/诊断入口。刷新时不能把已有可用状态突然变为空白。

## 手势与键盘

- 记账按钮长按阈值 480 ms；按住滑至目标并松手进入，未命中取消。桌面右键和预览菜单提供等价检查入口。
- 账单长按、账本长按均保留可见的操作按钮入口。
- 滚轮支持触屏滚动、鼠标滚动、点击以及键盘上下键；确认才写入，二月和闰年切换校验日期。
- 弹窗和菜单支持 Escape、关闭按钮和焦点范围；保留键盘焦点样式。
- 动效遵守系统减少动画设置。状态、选择和错误均有文字或图标辅助，不能只靠颜色。

安全视口高度小于 720 使用紧凑记账组合：紧凑金额常驻 + 剩余高度分类滚动 + 44 高快捷栏 + 固定数字键和三段保存。二级分类最多两行（92），窄屏两列。详见 [紧凑设计大图](../boards/compact-pages.html)。这属于原组件的布局变体，不新增第二套主题或业务请求。

## 成功、失败与轻提示

此前只有行内反馈的简略样例，缺少轻提示浮层的完整稿；本次补充到规范第 26、33 组与 [反馈交互页](../prototype/demo.html?page=flow-feedback)。

- **轻提示 BeeToast**：位于安全区下 12，左右至少 20，最大宽 340，内容决定高度且不低于 44；圆角 14，内边距 14 / 12；图标 20，与文字间距 8；正文 13、行高 1.5。大字或长文自然换行。
- 浅色用深色中性底与白字，深色用浅色中性底与深字。只将成功/失败图标设为语义色，均有文字与不同图标，不随主题色改变语义。
- 轻提示不抢焦点、不阻断触摸、不改变列表布局；2 秒消失，连续触发替换旧提示。
- **持续状态 BeeStatus**：成功、差异、失败留在原内容中，高度随内容；标题 13，原因 11。需要恢复操作的错误必须保留原因和“重试”，不能只靠会消失的轻提示。
- 打开弹窗和底部弹层时结束旧输入焦点，关闭后不重新聚焦已滚出屏幕的输入框；原输入内容、选择值与滚动位置保留。

## 规范目录组织

HTML 分为“基础组件 / beecount_ui”和“业务组件 / beecount_business_ui”两个大区：基础 22 组、业务 27 组，合计 49 组视觉样例。全部按行平铺；侧栏与手机定位只负责滚动到对应位置，不切换或替换样例。搜索按名称、描述和状态筛选，清空恢复全部。

组件分组及 Flutter 目录映射在 `catalog.json`。基础主题、表单、选择、导航、布局、弹层、反馈与业务账单、账本、分类、币种、同步、导入/分享分别归档。新增基础状态源在 `prototype/src/foundation-samples.cjs` 与 `foundation.css`，规范浏览器源在 `guide.css` / `guide.js`。

重建运行 `npm run build && npm run guide && npm run index`；输出整张规范图以及 `ui-foundation-*`、`ui-business-*` 的浅深色 PNG / SVG。HTML 为视觉规范；交互验收仍使用原 App 内的两个 Flutter 页面，新增状态与分组尚未同步在线 Figma。

## 时间与交易行补充（2026-10-23）

交易行已扩展为 60 个共享样例（保留原48、补4个重点与8个交叉组合），按 C3 两至三行规范展示。`BeeTransactionRow` 增加 `happenedAt`、`showTime`、`showFullDate`、`accountName`、`ledgerName`，不再将时间预先写死在 `subtitle` 中。

| 条件 | 与现有组件一致的展示 |
| --- | --- |
| 普通列表开启时间 | `HH:mm:ss`，整分钟也保留 `:00` |
| 普通列表关闭时间 | 隐藏时间，账户 / 附件 / 统计标记继续展示 |
| 时间为 `00:00:00` | 普通列表省略；`00:00:07` 等非零秒继续展示 |
| 完整日期模式 | `yyyy-MM-dd HH:mm`，不受时间开关影响，零点仍显示 |
| 没有时间值 | 不补造当前时间 |
| 时间与其他信息同显 | 时间置于右下；普通场景两行，复杂最多三行。账本是标签，排除规则是文字，更多次级字段通过明确入口只读查看 |

完整日期用于搜索；普通明细、日历、分类和标签详情沿用时间开关。对照测试实际渲染原 `TransactionListItem` 和新版组件，逐例比较时间输出，不能用一条静态 `12:34` 当作时间逻辑已覆盖。

## 皮肤卡片（R70）

`BeeSkinChoice` 与 `BeeSkinCard` 接收实际预览 Widget、名称、选中身份、动态/固定配色标记与受控回调；组件包不读取 Provider、不保存偏好。App binding 读取原注册表与当前主题，继续调用原 `applyHeaderSkin`。标签换行，预览移除状态栏内边距；只读卡片保留身份且禁用点击。Flutter 业务目录第 45 节包含演示、只读、当前真实皮肤及真实设置入口，HTML 对应 B41。

皮肤页保留全部/动态/静态三种筛选、五个原系列及基础纯色。正式版 22 项（含纯色），调试版保留原 SVG 示例，共 23 项。`tokens/skin-registry.json` 冻结旧身份、系列、名称与亮暗缩略图 SHA；两款固定配色动态皮肤及恢复记忆主题色的逻辑沿用原服务。HTML 缩略图引用原 Flutter 导出，动态预览仍使用已有 Canvas 画面；静态缩略图基准为原蜜蜂黄，其他主题的实际绘制以 Flutter 为准。


## 文件任务与归档确认（R71）

`BeeFileTransferStatus` 覆盖就绪、处理中、成功、部分失败与失败，传入真实任务状态、进度、结果及独立预览回调。`BeeArchiveSummary` 展示文件名、附件/图标/头像信息及跳过/覆盖草稿，确认/预览/取消继续在原弹窗内。两个组件不请求数据、不读写归档；App `AttachmentTransferActions` 调用原服务，`LiveFileWorkflowPreview` 读取原文件扫描和后台导入 Provider。Flutter 业务第46节和 HTML B42 同时覆盖这些状态。

原跳过策略同时检查文件及数据库记录；存在记录但文件缺失时也跳过，覆盖模式会重建附件记录。临时真实数据库/文件回归验证此契约。归档实际格式为 TAR.GZ，原文件选择器还允许 `.tar`，服务固定 gzip 解码的差异记入 Q16；本轮不宣称原始 TAR 导入已实现。平台文件选择与分享留在 App，图标与原型使用相同 Lucide 路径。


## 附件与图标预览库

规范 B43/spec68，对应 Flutter 业务47。三列、8间隔、13圆角、17页面留白，尺寸和文件大小放右下角。总数为0时隐藏页签；单组为空仍能切换另一组。两个分组支持点击和左右滑动，关闭只读缩放弹窗后恢复选中态。原本地文件和归档字节使用同一结构，不增加原业务没有的账本筛选。完整长文件名在弹窗内换行，坏图保留文件信息；设计图片中的尺寸与大小来自图片实际头部和字节数。

## C3 交易行自适应（2026-10-26，已批准）

- 日常用途、金额、账户、附件与两枚小标签尽量两行；复杂最多三行，不固定三行。备注有值时，下方不重复分类。分类图标进分类详情，行点击仍编辑，长按菜单保留独立详情入口，右侧不加省略号。
- 原币和历史折算完整显示，不使用 FittedBox 缩小金额。根据真实字体与缩放测量宽度；大金额使用完整宽度变体。时间沿用原偏好与格式，不重算金额、汇率或快照。
- 不计收支／不计预算保持可见文字；账本名称始终是小标签。长名称可省略并点开完整值；标签最多两枚＋N，过密时账户、附件、标签等次级字段明确合并为“更多N项”，只读与批量也能查看完整字段，不改选择或交易。
