## 字体与视觉复核

Figma 导入使用可用的 Noto Sans SC，并统一为 Regular / Bold，避免系统字体缺失导致错误换行。本地 demo 与原始 PNG 继续使用原来的系统字体。字体度量、字重、抗锯齿和部分浏览器模糊/遮罩在两种环境中可能有轻微差异；原始 PNG 和 HTML 是视觉参考。

已检查首页、记账、横排标签、初始化、皮肤和组件规范；补齐了导入器漏掉的输入值、备注、搜索提示和配置字段。图层与页面清单记录在 `../qa/figma-native.json`，核对截图在 `../qa/figma-*.png`。

## 本地资源与重新导入

- `html/`：经字体、边框、滚动裁切和伪元素转换后的 HTML 导入源。重新生成：`npm run figma:sources`。
- `fonts/`：仅用于导入源的 Noto Sans SC 字体及 OFL 许可，不安装系统字体。
- 各场景 `.svg`、`pages-board.svg`、`ui-components-{light,dark}.svg`：保留文字、形状、图标和离散图片的矢量备份。
- 对应原始 PNG 在 `../screens/` 与 `../boards/`，完整长页可在 `screens/full/` 查看。

`html/` 与 `dom-snapshots.json` 属于可重新生成的临时导入产物，默认不纳入 Git；HTML demo、布局源、PNG、SVG、规范、字体许可与构建脚本保留在项目中。

当前保存的是原生在线 Figma Design 文件，没有将 SVG 改后缀伪装成 `.fig`。本地离线 `.fig` 尚未导出；如需离线副本，可在 Figma 的文件菜单执行 **Save local copy**。

当前本地为 216 个场景、59 组规范，以及第 8 版记账布局；新增补充尚未同步在线 Figma。连接/文件信息保存在 `connection.json`；qa 下旧同步过程记录和截图只保留本地。逐页 SVG、导入 HTML 和字体不首次提交到 Git，按脚本在本机生成。
