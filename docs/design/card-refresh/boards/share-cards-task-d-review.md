# 子任务 D：分享与卡片评审

状态：**仅 HTML 设计评审，等待用户确认。** 不替换 Flutter、主 demo、组件包、页面清单或隔离验收环境。

预览：`boards/share-cards-task-d-review.html`。全部 CSS、脚本、蜜蜂 SVG、公开项目二维码均内聚在单个 HTML 中，不需要接口、外部字体或网络素材。手机直览支持 `?mode=phone&kind=month`、`kind=profile/app/year/ledger/annual/receipt`；数据支持 `&data=long/empty/negative/foreign`；页面保留完整平铺样式供检查。

## 基准与方向

沿用已确认的 A 洞察、B 资产的白 / 浅灰卡片、清楚的深色排版、克制主题色、圆角与线性图标。A、B 原稿与主 demo 未改。C 明细行也不在此任务范围。

分享海报采用纸色和完整的品牌排版，档案以记账天数形成记忆点，应用分享保留原标语和六项能力。财务海报强调统计层级与分类金额，使用同一主题色呈现占比。小票保留虚线、纸张边缘与等宽日期，不强行做成普通白卡。

默认无皮肤。礼花 / 柔光为本稿提出的两种可选皮肤处理示意，**不是宣称已与现有 Flutter 皮肤引擎接通**；动效可暂停，减少动态效果的系统偏好自动禁用动画。静态导出以当前预览帧为准的交互可演示，但本评审不生成真实系统相册文件，也不发送分享。

## 与现有功能的边界

- **Q19 A**：保留用户档案与应用分享模板，默认仍为两个选项。月度 / 年度 / 账本由原入口打开对应内容；本稿右侧下拉是验收工具，不是要把所有类型塞进产品页。
- 生产分享仍是 `ShareCardDialog` 的短路径，本稿手机壳用于演示弹窗内容；不会用新页面替代原弹窗。
- `UserProfilePosterData` 当前没有昵称字段。使用 `ledgerName`，未把它改成昵称。若未来加入昵称，需另外确认模型扩展；本稿没有删除档案原字段。
- 金额隐私沿用“隐藏收入和结余”：支出、支出分类金额继续展示；收入分类金额、收入总额、结余、月均收入、结余率隐藏。档案 / 应用没有金额隐私开关。
- 小票保留交易原币，不自行追加查询时汇率；没有将历史账单重写为其他币种。外币数据是本地合成单位情形，不请求汇率服务。
- 保存演示成功 / 权限不足 / 失败；加载与生成失败禁止导出；分享有完成 / 取消 / 不可用，取消不显示成功。操作带忙碌保护。
- 主题色不替代成功、提醒和错误的语义。纸色独立于 App 深色外观；深色海报为额外可选，小票保持浅纸色。
