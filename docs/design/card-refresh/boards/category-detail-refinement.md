# 分类详情精修交互稿

状态：**独立 HTML 待用户确认，未改 Flutter，未替换主 demo。**

预览：`http://127.0.0.1:8374/boards/category-detail-refinement.html`

本稿只聚焦用户提出的三个问题：月 / 年 / 全部 Tab 太高、时间选择过于分散、父分类入口重复且占据独立空间。保留当前分类详情中的统计字段与已有操作入口；所有数据均为本页固定合成示例，不请求或修改真实账本。

## 设计

1. **紧凑周期 Tab。** 轨道视觉高度 32px，选中底片 28px；外部真实按钮点击高度仍为 44px。颜色和圆角沿用 v4 卡片体系，三项等宽。
2. **独立时间范围行。** 月 / 年模式的当前范围居中，左右切换前后周期；点击范围从底部打开滚轮。全部模式显示“全部时间”，无需左右翻页。默认值继续为“全部”，遵守 Q10。
3. **上级入口收进摘要卡。** 在当前分类身份上方，用“上级 + 父分类名称 + 箭头”小入口表示关系。父分类名称只出现一次；摘要副文案只保留分类层级与账本。长父名单行省略，完整内容保留在可访问名称和提示里；点击实际切换到父分类，并可返回原子分类。一级分类不留空占位。
4. **主体字段保留。** 当前分类名称、图标、自定义图片、累计 / 本月 / 本年金额、币种、记录笔数、单笔均额、占比、二级分类明细和占比条、累计趋势、排序、关联交易及记账入口继续存在。长分类标题最多两行。

本次不重做统计逻辑，不新增筛选类型，不改变默认统计范围，不新增皮肤或全局配色。

## 可交互范围

- 7 个案例：二级分类、一级分类、长名称二级、长名称一级、暂无记录、收入分类、跨账本外币。
- 月 / 年 / 全部切换会真实筛选合成数据；左右按钮改变范围。
- 底部滚轮支持鼠标滚动、触屏滚动、点击选项以及上下方向键；取消不保存，确认后更新页面范围。支持 2000—2100 年。
- 父分类与二级分类点击后实际进入相应详情；返回恢复上一分类。
- 点击趋势柱查看对应累计金额；四种排序、展开 / 收起全部交易、交易详情都可操作。
- 分类操作保留搜索、编辑、迁移、管理四个入口。搜索筛选本页示例备注；编辑只改本页示例分类名；管理列表可进入分类。迁移展示来源、目标选择和预览，不执行真实迁移。记账入口展示预选分类，不创建账单。
- 外币案例保留原币、历史折算、账本标签和时间；汇总说明遵守已有历史金额 + 查询时汇率规则，固定演示汇率不代表线上行情。
- 弹层限定在手机预览中；关闭保持底层滚动位置，支持 Escape、焦点返回与焦点循环。
