预览边界

原实现，与应用方式分开确认。

此页运行从官方3.9.0提取的 Flutter Painter 与 Widget，没有启动 App、数据库或云同步。原窗口透明区域保留，原画自身的底色也保留；承载区外侧只延续其静态底色。浏览器 CanvasKit 的字体、抗锯齿与 Android 可能不同，不宣称跨平台逐像素一致。

标准首页保持固定顶部与列表局部滚动；小屏整页滚动时，场景跟随承载区域离场。打开弹窗暂停背景，进入记账页收起场景。“我的”紧凑余额卡保留留白，原画在顶部资料区域完整承载。
