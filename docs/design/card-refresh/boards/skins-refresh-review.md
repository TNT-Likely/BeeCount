## 原设计调查

- 两款现有动态皮肤为 `anniversary`（一岁星座）与 `anniv_cake`（周年蛋糕），来自 `lib/styles/header_skins/`。原本的星座数字1、小蜜蜂巡游、烛火和彩带有明确主体，不应只剩模糊底色。
- 原 `PrimaryHeader` 将绘制限制在头部。星座原注释明确保留右上净空，蛋糕也避让收入/余额等内容；它们是按顶部画布构图的。
- 当前 `V4PageScaffold` 把原皮肤 painter 放进全屏背景槽。原有按画布高度计算的锚点、渐变和主体位置随整页高度变化，容易分散画面重心。
- 本稿把“顶部场景”和“整页底色”分成两层：标准844高屏的场景约280px，568小屏约193px；下方只保留同色系的柔和底色渐变。卡片与文字保持原有位置。

## 渐变和可读性

每款只沿相邻色系过渡，不混合互补色，也不把大块模糊光斑压在金额上。顶部色彩更明确，经过中段的浅色过渡回到底色；深夜单独设定色阶，不能简单降低日间透明度。

卡片保留约96%的原纸面色，交易行保持原背景；装饰层不接受鼠标或触摸，排除辅助功能语义。首页的星座、蛋糕会向净空处平移，避免与右侧 AI/搜索/更多重叠；“我的 A”沿用更宽的右侧空白。

“主题色”控制主界面按钮颜色，皮肤主体仍有自己的调色板。此处只比较搭配，不改变原两款皮肤的固定配色注册规则；C/D 也尚未登记为正式皮肤。

## 动效如何看

- A：星光轻呼吸，小蜜蜂缓慢浮动；不整体缩放背景。
- B：烛火小角度摆动，彩带缓慢起伏。
- C：两层光带沿不同方向缓慢舒展，单次周期24–30秒。
- D：前层山形和等高线仅移动数像素，约32秒周期。
- 暂停：停在当前动画帧，不重新跳回起点。
- 减弱：保留静态构图，关闭装饰动画；系统 `prefers-reduced-motion` 优先于播放控制。

这只是浏览器动效交互设计。实际 Flutter 的帧率、电量、低端机表现及后台生命周期尚未验收，不将静态截图或 CSS 动效运行视为原生性能通过。

## 交互控制

四方案平铺，支持快速定位、选中预览、首页/我的A、390×844/320×568/414×896、白天/深夜、四主题色、清淡/标准/更浓、播放/暂停/减弱，以及无皮肤对照。选中只影响评审页，不代表用户已批准实施；最终方向仍由用户在聊天里确认。

手机内继续使用现有交互：金额显示/隐藏、账本选择、分类详情、昵称编辑、数据管理等菜单。改变页面或打开弹窗后，背景层会重建，但不会挡住原控件。
