# 账户图标一致性 · 两种方案确认稿

状态：待用户确认，只新增独立 HTML Demo，没有修改 Flutter 或主交互稿。

打开：<http://127.0.0.1:8374/boards/account-icon-consistency-review.html>

**建议采用 A：所有账户入口统一使用原 SVG 配色。** 当前 SVG 已包含品牌色和图形内部层次，统一调用后即可解决选择器无色、不一致的问题。主题色仅用于选择边框、勾和主操作。

## 为什么需要统一

- `lib/utils/account_type_utils.dart`：`AccountTypeIcon` 已统一各类型 SVG，默认保留原色。`monochrome: true` 与 `color` 会使用 `BlendMode.srcIn` 整体染色。未知类型回退到 `other_account.svg`。
- `lib/widgets/biz/account_selector.dart`：expanded picker 当前构造 `BeeLineIcon`，将账户归为 Banknote / CreditCard / Wallet，绕过原 SVG。这是选择器与其他账户入口不一致的直接原因。
- Demo 使用仓库 `assets/icons/` 中原始 SVG 的 Base64 字节快照，保证通过现有局部 HTTP 服务和本地文件均可打开。没有改写图片颜色，也不依赖外网图片。

## 两种方案

| 方案 | 规则 | 权衡 |
| --- | --- | --- |
| A · 原 SVG 配色（建议） | 资产列表、选择弹窗、详情摘要、类型选择复用原 SVG；浅深主题图形一致 | 品牌识别清晰，保留卡片内部细节，信息更丰富 |
| B · 中性单色 | 同一 SVG 的透明度轮廓统一染为中性墨色，浅深主题分别调整中性色 | 视觉克制；但现有 SVG 具有不透明实心底板，整体 `srcIn` 染色会合并银行卡等图形内部细节 |

B 使用 CSS alpha mask 模拟 `BlendMode.srcIn` 的实际整体染色效果，没有偷偷换为另一套线条图标。两种模式都会贯穿四个入口。可打开同屏对照，一次比较四处。

## 本稿中的交互与边界

- 资产列表点击账户进入详情；账户选择支持搜索、选择、无账户及按示例币种过滤。
- 历史隐藏账户场景只将当前钉住的隐藏账户补回，并保留原账户图标与“已隐藏”文字；不把原图标替换为眼睛图标。
- 自定义 / 未知类型统一使用现有其他账户 SVG 兜底。
- 类型选择含 12 个正式类型，按日常与估值分组；切换分组保留草稿，保存后示例账户在其他入口同步改变。
- 仅为图标设计确认而允许示例变更类型，不代表放宽 Flutter 中已有的账户类型编辑限制。产品真实权限、历史数据和可交易类型校验仍须沿用原规则。
- 398×844 / 320×568，浅深主题与 3 种主题色。资产页底部导航为现有稿的 66px；子页使用自己的头部与操作区。

## 验收

Chrome / Playwright 检查 398 与 320 两种宽度 × 浅深主题四个组合：两种图标模式的四个入口均能显示真实 SVG，搜索、账户切换、未知类型兜底、隐藏账户、USD 过滤、类型分组及保存、同屏对比、无横向溢出。底部导航保持 66px。

只使用合成数据，设计方案尚未应用到 Flutter。
