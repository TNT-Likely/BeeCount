## 保留的行为与数据边界

- Q19：默认仍是档案与应用两个模板；其他原入口只打开对应财务类型。缩放、滑动模板、缓存与生成 token、忙碌保护、原弹窗、关闭与取消行为保留。
- 收入隐私遮盖收入总额、收入分类金额、月均收入和结余；支出继续展示。年度长图保留原“记账坚持”的隐私替代统计。
- 保存权限不足、失败和成功，以及系统分享取消 / 不可用处理，继续使用原平台服务；本次未增加真实发送渠道。
- 摘要仍使用原历史折算与聚合结果。仅为三个摘要海报补入所选账本的币种显示元数据，不重算、不回写交易。小票继续读取交易原币金额，不用本位币或当前汇率替换；JPY 等币种保留原精度。
- 小票默认开启备注 / 标签，默认关闭账户 / 账本。转账账户同样遵从原账户字段开关。它与独立稿中无条件展示合成转账账户的示意相比，以原产品控制规则为准。
- 年度海报特别时刻备注与分类名称保留摘要形式，超长内容最多三行；原有年度海报曾将备注限制为一行，小票继续保留完整备注。
- 原模型没有昵称字段，未用昵称替换 `ledgerName`，也未扩展用户档案模型。
- D 默认采用纸色、无皮肤与现有主题色。独立评审的可选礼花 / 柔光 / 深色纸张开关不擅自扩为正式设置；当前原生导出继续使用固定浅纸色，没有新增动态皮肤导出配置。
- 预算原正常 / 提醒 / 危险 / 超额阈值与状态语义不变；仅正常概览的装饰进度采用主题色。同步组件不发请求，状态与全部计数来自原绑定。
