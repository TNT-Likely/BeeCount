# 蜜蜂记账 4.0.0 Beta 2

继续完善 4.0 卡片界面，欢迎验证日常记账、账本切换和大数据量体验。

## 更新摘要

- 首页先准备完整首屏账单再显示，分类、标签、折算和汇总一起呈现。
- 修复洞察页支出、收入、结余三个视角切换时的内容闪动。
- 统一分类与账户图标，精简头像区域，并调整页面对齐和留白。
- 原画皮肤限定在合适区域呈现，保留画面风格并让主要内容清晰可读。

## 安装与升级

- 本次仅提供正式签名的 Android ARM64 APK，适用于支持 ARM64 的 Android 设备；不发布到应用商店或 TestFlight。
- 正式包可覆盖升级已有蜜蜂记账。升级前请先在应用内导出账本及配置备份，保留原文件。
- 这是测试版本，功能与兼容性仍需继续验证。旧版通常不能直接覆盖安装更高 versionCode 的版本，请不要为降级卸载应用，以免清除本地数据。
- APK 通过包名、签名、ARM64、Release/AOT、素材排除和对齐检查；这些检查不等同于所有设备、云同步和数据场景的完整验收。
