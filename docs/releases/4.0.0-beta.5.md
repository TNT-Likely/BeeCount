# 蜜蜂记账 4.0.0 Beta 5

本次集中修复 Beta 反馈的显示、间距与操作问题，恢复整页皮肤，并将 Android 和 iOS 内测合并到同一发布入口。

## 更新摘要

- 皮肤恢复选择并融入整页、延伸到状态栏；底部导航改为稳定的不透明底色，保留皮肤装饰。
- 记账页转账金额区恢复间距，空白或零金额切换不再打扰；已有输入及预填内容仍受保护。
- 预算管理恢复环形进度与剩余额度布局，调整洞察页周期 Tab 和外币折算提示的比例。
- 修复暗黑模式按钮图标与文字颜色不一致，统一关于页官方网站图标的中性色。
- 收紧明细列表日期分组间距，统一账户、分类、标签详情及搜索交易列表的左侧对齐。

## 安装与升级

- Android 仅提供正式签名的 ARM64 APK，可覆盖升级同签名的 3.9.0 和早期 4.0 Beta。
- Beta 5 的 Android versionCode 为 230；4.0.0 正式版仍计划从 300 开始递增。
- iOS 的数字版本为 4.0.0，默认 build 230；IPA 是 App Store 分发签名，不能直接侧载，安装须通过 TestFlight。
- 两端共用本 Release。iOS 构建、Apple 处理、测试组及外部审核的实际状态以 Actions / App Store Connect 为准。
- 升级前请导出账本、配置并保留备份文件。不要卸载应用降级，以免清除本地数据。
- 本次不发布到 Google Play，不提交正式 App Store 审核。

## 验证范围与反馈

- 完成本轮 Flutter 回归、亮暗及大小屏组件检查，并复用保留数据的隔离 Android 环境增量验收。
- 请重点检查皮肤、底部导航滚动稳定性、转账切换、预算与多种交易列表。
- 未覆盖全部机型和云服务组合；本轮不改变 Cloud 恢复和同步规则。
