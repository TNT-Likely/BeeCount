# 蜜蜂记账 4.0.0 Beta 3

本次主要根据 Beta 2 反馈调整详情页、选择器和金额显示，继续验证日常记账与升级体验。

## 更新摘要

- 精简子页面顶部 Tab，优化分类详情的周期、时间与上级分类展示。
- 恢复账户详情卡片层次，保留真实历史余额、收支与转账入口。
- 收紧标签尺寸，统一账户原色图标，并同步组件验收页与设计稿。
- 修复余额切换简写不生效、小票菜单图标缺失及旧 Tab 长按水波纹。
- 修复关于页推荐分享卡片生成失败，社交媒体图标恢复平台颜色。

## 安装与升级

- 本次仅提供正式签名的 Android ARM64 APK，不发布到应用商店或 TestFlight。
- 可覆盖升级同签名的正式版与早期 4.0 Beta。升级前请在应用内导出账本和配置并保留备份文件。
- Beta 3 使用 versionCode 228；4.0.0 正式版计划从 300 开始，之后正常递增。
- 请勿通过卸载应用降级，以免清除本地数据。

## 已知问题与验证边界

- 已完成相关单元、页面与组件回归；构建检查不代表全部设备、数据组合与云同步均已验证。
- 两款动态皮肤的下一轮视觉优化仍在独立设计中，本次保留现有皮肤。
- 欢迎重点反馈分类与账户详情、标签选择、金额简写及旧版升级体验。
