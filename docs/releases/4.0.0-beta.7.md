# 蜜蜂记账 4.0.0 Beta 7

本次继续完善 v4 的界面与记账体验，修复分类选择、日历和反馈提示，并精简静态皮肤。

## 更新摘要

- 有子分类的分类只用于展开，展开区不再重复展示父分类；没有子分类的一级分类仍可直接记账。
- 自动记账采用新的紧凑进度卡，区分识别与保存阶段；成功、错误、提醒和普通消息使用不同图标。
- 记账页顶部 Tab 与下方卡片统一间距，普通屏和小屏保持一致的布局节奏。
- 日历仅有收入或支出时金额紧随日期；空日期选中态更紧凑，记账按钮使用主题色；关于页移除重复帮助入口。
- 静态皮肤保留极光和山峦，优化极光的深色光带与页面衔接；两款周年动态皮肤继续保留。

## 安装与升级

- Android 提供正式签名 ARM64 APK，可覆盖安装同签名旧版；升级前建议导出账本、配置及附件。
- iOS 提供 App Store 分发签名 IPA，并通过 TestFlight 交付；IPA 不支持直接侧载。
- 已移除静态皮肤的已有选择会回退至纯色，恢复用户自己的主题色；账单、账户、分类及附件不受影响。
- 两端构建和 Apple 处理完成后才公开同一个 Release，并发送一条通知。公开附件仅含 APK 和 IPA。
- 不上传 Google Play，不提交正式 App Store 审核；不要通过卸载或直接降级回退测试版。

## 验证范围与已知边界

- 已完成 Flutter 回归、组件与设计契约检查、小屏大字和深浅主题验证，以及独立 iOS 环境的真实分类记账、日历与正常入口重启验收。
- Loading 的真实保存阶段通过本地数据库服务测试；原生界面验证不代表重测了所有 AI 服务商或 Cloud 渠道。
- 本次未变更免费范围、收费方案、数据库结构或 Cloud 同步协议。具体设备兼容性和业务组合仍需内测反馈。
