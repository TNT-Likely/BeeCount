# 蜜蜂记账 4.0.0 Beta 6

本次增加可选的首页紧凑汇总，继续完善 Beta5 反馈的交易列表、账户详情和深色模式。

## 更新摘要

- 首页“更多”新增紧凑汇总：支出与预算环同屏，收入和结余保持上下层级；默认保留完整长版，手动选择会保存。
- 交易行的账户、账本和标签会利用空余宽度；账户详情切换全部记录时保留页面，减少截断和闪烁。
- 修复深色模式默认头像、底部导航遮挡末行，以及记账页顶部页签与金额区域相连的问题。
- 关于页恢复原有主体，保留新版更多产品卡片；皮肤卡片透明度、背景模糊可调整并保存。
- 统一明细行与卡片的透明材质；Beta 下载附件精简为 ARM64 APK 和 IPA，双端成功后统一通知。

## 安装与升级

- Android 仅提供正式签名 ARM64 APK，覆盖安装同签名旧版，保留原有数据；安装前仍请导出账本、配置及附件。
- Beta 的安装码由统一门禁按最高已交付版本递增，4.0.0 正式版从至少 300 开始。实际版本和安装码以本次构建回执为准。
- Android 与 iOS 共用一次发布，默认在签名构建及 TestFlight 的 Apple 处理完成后再公开同一个 Release，并发送一条通知。
- 公开附件仅保留 APK 和 IPA；签名、摘要和版本校验继续执行，机器校验记录保存在发布说明的隐藏元数据中。
- IPA 使用 App Store 分发签名，不能直接侧载；TestFlight 测试组、加密合规和外测审核以 App Store Connect 为准。
- 不上传 Google Play，不提交正式 App Store 审核，不要通过卸载或直接降级来回退内测版。

## 验证范围与反馈

- 已完成相关组件、深浅主题、小屏大字、配置持久化、HTML 交互及 Flutter 自动回归。

- 本次没有更改 Cloud 恢复与同步规则。卡片材质默认为原有覆盖程度、无模糊；可随时恢复默认。
