# 蜜蜂记账 4.0.0 Beta 4

本次根据 Beta 3 反馈优化分类、账户流水与皮肤，并整理页面和组件目录。

## 更新摘要

- 一岁星座、生日蛋糕与静态皮肤融入顶部和首卡，沿用原版动画和底栏装饰，内容位置保持不变。
- 二级分类按四列自适应，长名称自动占两格，保留原图标和分类顺序。
- 优化账户详情余额对齐、去除重复信息，完善流水筛选和排序提示，修复账户搜索关闭时的错误。
- 统一时间与筛选弹层，分类详情选择“全部”时收起重复时间筛选；从分类管理返回洞察保留原内容。
- 分类排序增加更容易抓取的拖动把手，连续排序按顺序保存，修复排序后离开页面可能出现的错误。

## 安装与升级

- 仅提供正式签名的 Android ARM64 APK，不发布到 Google Play 或 TestFlight。
- 可覆盖升级同签名的 3.9.0 与早期 4.0 Beta。升级前请导出账本、配置并保留备份文件。
- Beta 4 使用 versionCode 229；4.0.0 正式版仍计划从 300 开始递增。
- 请勿通过卸载应用降级，以免清除本地数据。

## 验证范围与反馈

- 完成本轮 App 单元、组件与页面回归，并使用保留数据的隔离 Android 环境增量验收；尚未覆盖全部机型和云服务组合。
- 本轮没有修改 Cloud 恢复逻辑；请继续保留原有数据与云配置备份。
- 欢迎重点反馈皮肤、长分类名称、分类拖动、账户流水与旧版升级体验。
